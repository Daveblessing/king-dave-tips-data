# King Dave Tips — données publiques

Ce dépôt contient uniquement les données publiques du site [King Dave Tips](https://king-dave-tips.vercel.app) : calendrier, probabilités du modèle, registre et messages du jour.

Aucune clé, aucun jeton, aucun secret. Les pronostics sont des estimations, sans garantie de gain. Réservé aux majeurs (18+). Jouez responsable.

Mise à jour automatique depuis le serveur Saturne Tip's, plusieurs fois par heure, tant que le serveur tourne.
